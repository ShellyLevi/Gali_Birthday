# תיקיית תמונות ומדיה

## איך להוסיף תמונות לסרטון

1. שמרי את התמונות שלכן בתיקייה זו:
   public/media/photos/

2. קבצי תמונות נתמכים: .jpg, .jpeg, .png, .webp, .gif

3. המלצה: שמרי קבצים עם שמות ברורים כמו:
   - gali_01.jpg
   - gali_02.jpg
   - וכו'

## קבצי אודיו

קבצי האודיו נמצאים ב-public/:
- hamitratz.mp3 - נגינה במסך 2-5
- count_on_me.mp3 - נגינה במסך 6

## פיתוח

להרצת האפליקציה:
  npm run dev

לבנייה לפרודקשן:
  npm run build
